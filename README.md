# 로어북 스튜디오 & 번역기 · RisuAI 플러그인

RisuAI에 등록된 캐릭터의 **로어북 항목과 봇 디스크립션**을 가져와 직접 편집하거나, RisuAI에 연결된 메인·보조 모델로 수정·번역하는 API 3.0 플러그인입니다.

현재 정식 배포 버전은 **1.0.0**입니다. 포함 기능과 설치 안내는 `docs/RELEASE_NOTES.md`에서 확인할 수 있습니다.

[설치용 JS 다운로드](https://raw.githubusercontent.com/cocoone012/lorebook-studio/main/dist/lorebook-studio-v1.0.0.js) · [GitHub 저장소](https://github.com/cocoone012/lorebook-studio)

## 설치

전달용 설치 파일은 버전을 붙인 `dist/lorebook-studio-v1.0.0.js`입니다. 개발용 고정 이름 `dist/lorebook-studio.js`와 내용은 같습니다. 빌드할 때 현재 버전의 파일을 함께 생성합니다.

함께 생성되는 `dist/lorebook-studio.json`은 동일한 코드와 메타데이터를 담은 보관용 레코드입니다. 실제 앱 테스트 순서는 `docs/REAL_RISU_TEST.md`를 참고하세요.

1. RisuAI 설정 → 플러그인 → 아래쪽 `+` 버튼에서 `dist/lorebook-studio-v1.0.0.js`를 가져옵니다. 기존 설치가 있으면 업데이트 안내를 확인합니다.
2. 설정 또는 햄버거 메뉴에 추가된 **로어북 스튜디오 & 번역기**를 엽니다.
3. RisuAI에서 요청하는 캐릭터 데이터 읽기·쓰기 권한을 허용합니다. 쓰기는 반영할 때 필요합니다.
4. **디스크립션 / 로어북 / 기타 번역** 탭에서 작업 종류를 선택합니다. 디스크립션 탭에서는 캐릭터를, 로어북 탭에서는 캐릭터와 로어북을 선택한 뒤 **그대로 불러오기** 또는 **AI로 불러오기**를 누릅니다.

최신 RisuAI API 3.0을 기준으로 만들었습니다. 메인·보조 모델은 RisuAI에서 먼저 설정해 두세요. 별도 API 키 입력 없이 기존 연결을 사용합니다. 선택한 모델로 실행하는 요청에는 해당 모델의 사용량이 발생합니다.

### 업데이트

RisuAI 플러그인 목록에는 **로어북 스튜디오 & 번역기 v1.0**으로 표시됩니다. 이 GitHub 배포본은 업데이트 주소를 포함합니다. 이후 새 버전을 GitHub에 올리면 RisuAI가 버전을 확인해 해당 플러그인 옆에 업데이트 `+`를 표시합니다.

업데이트 주소가 없던 이전 설치본은 이 배포본을 한 번 수동으로 다시 가져오세요. 실제 업데이트 주소는 고정 파일 `dist/lorebook-studio.js`를 사용합니다. GitHub에 반영하려면 수정 후 빌드·테스트를 거쳐 변경 내용을 커밋하고 업로드해야 합니다. 로컬 파일 저장만으로는 GitHub에 올라가지 않습니다.

## 작업 방식

| 기능 | 동작 |
| --- | --- |
| 직접 편집 | 작업판 본문을 직접 수정합니다. 로어북의 이름·키워드·발동 설정은 오른쪽 위 설정 버튼에서 수정합니다. |
| AI 수정 | AI로 불러오기를 누르고 원하는 수정 내용을 입력하면 원본을 수정해 작업판에 가져옵니다. 실제 데이터 저장은 반영 버튼으로 완료합니다. |
| 기본 프롬프트 | 상단 설정창의 **AI로 불러오기 기본 프롬프트**를 직접 수정합니다. 수정 즉시 이후 AI 불러오기에 사용되고 기기에 자동 저장되어 재실행 후에도 유지됩니다. 전체·부분 번역 프롬프트는 별도로 유지됩니다. |
| 전체 번역 | 한국어 또는 영어 번역문을 별도 칸에 표시합니다. 디스크립션·로어북에서는 본문 아래, 기타 번역에서는 오른쪽에 출력하며 원문을 교체하지 않습니다. |
| 부분 번역 | 작업판 본문에서 원하는 범위를 드래그하고 한국어/English를 누릅니다. AI 응답이 오면 **해당 범위가 바로 번역문으로 바뀝니다**. 되돌리기로 취소할 수 있습니다. |
| 모델 전환 | 상단 메인/보조 버튼으로 선택합니다. 이후 모든 AI 수정·번역은 선택한 모델로 처리합니다. 요청 중에는 선택을 고정합니다. |
| 모델명·연결 상태 | 버튼 옆에는 상태 점과 선택한 모델 이름만 표시합니다. 상태 문구는 표시하지 않으며 호출 성공은 녹색, 호출 오류·시간 초과는 붉은색, 확인 전은 회색입니다. |
| 기타 번역 | 왼쪽에 번역할 글을 입력합니다. 아래의 언어 선택·부분 번역·전체 번역으로 조작합니다. 드래그한 부분은 선택한 언어로 바로 교체하고, 전체 번역은 오른쪽 읽기 전용 칸에 출력합니다. 입력 내용은 자동 보관합니다. |
| 원본 반영 | 디스크립션 탭에서는 **디스크립션에 반영**, 로어북 탭에서는 **로어북에 반영**을 눌러 선택한 대상에 저장합니다. 부분 번역도 반영 전에는 작업판만 바뀝니다. |
| 화면 모드 | 상단 연결 확인 아이콘 옆 설정 버튼에서 **다크 모드 / 라이트 모드**를 선택합니다. 선택은 플러그인의 기기 로컬 저장소에 보관합니다. |

전체 번역은 **가져온 항목의 본문 전체 또는 디스크립션 전체**를 뜻합니다. 여러 로어북 항목을 한 번에 번역하는 일괄 작업은 포함하지 않습니다. 제목·키워드는 전체 번역의 대상에 포함하지 않습니다.

AI 응답을 기다리는 동안 본문을 수정한 경우, 부분 번역이 새 편집 내용을 덮어쓰지 않도록 적용을 중단합니다. 전체 번역 칸에는 요청 당시 원문에 대한 결과가 표시됩니다.

### 디스크립션 화면

캐릭터 선택 바로 아래 왼쪽에 읽기 전용 원본을 표시하고, 그 아래에 원본 토큰 수·언어 선택·전체 번역 버튼과 읽기 전용 번역 결과칸을 표시합니다. 원본 전체 번역은 편집칸에 불러오기 전에도 사용할 수 있으며 오른쪽 편집 내용과 별개로 처리합니다. 오른쪽에는 편집칸과 전체 번역칸을 처음부터 표시합니다. 두 섹션은 같은 너비이며 가운데 **AI로 불러오기 → / 그대로 불러오기 →** 버튼을 작은 한 줄 글씨로 표시하고, 위쪽 원본칸·편집칸의 세로 중앙에 배치했습니다. 원본은 항상 읽기 전용이고 오른쪽 편집칸은 불러오기 후 수정할 수 있습니다. AI로 불러오기는 요청한 수정 결과를 가져오며, 두 동작 모두 캐릭터 원본을 직접 변경하지 않습니다.

편집칸 아래 왼쪽에는 **약 N 토큰** 추정치를 표시합니다. 현재 API에서 모델별 토크나이저에 접근할 수 없어 문자 구성으로 추정하며 실제 모델 사용량과 다를 수 있습니다. 오른쪽에서 번역 언어, 전체 번역, 부분 번역, 원본 반영을 선택합니다. 전체 번역문은 버튼 아래의 더 짧은 읽기 전용 칸에 표시됩니다. 원본과 번역칸은 흐린 색, 편집칸은 선명한 색으로 구분합니다. 각 칸의 크기는 고정하며 긴 내용은 칸 안에서 스크롤합니다. 왼쪽과 오른쪽은 본문칸·버튼 모듈·번역칸의 크기가 각각 같으며 위아래 끝이 일치합니다. 데스크톱 화면 높이에 맞춰 본문·번역칸 높이를 줄였고 하단의 상시 상태바를 제거했습니다. 오류나 요청 대기 안내는 공간을 차지하지 않는 일시 알림으로 표시합니다. 편집칸 위의 아이콘으로 되돌리기·다시 실행·원본 백업에 접근할 수 있습니다. 좁은 화면에서는 두 섹션을 세로로 배치합니다.

### 로어북 화면

모바일(너비 800px 이하)에서는 원본 영역 전체 → 가운데 불러오기 버튼 두 개 → 작업 영역 전체 순서로 세로 배치합니다. 디스크립션도 같은 순서입니다. 반영 버튼의 문구는 가로·세로 중앙에 표시합니다.

디스크립션과 같은 원본·편집·번역 배치입니다. 상단 왼쪽의 같은 공간에 **캐릭터 선택 / 로어북 선택**을 나란히 표시하고, 로어북 선택 옆 검색 버튼으로 제목·키워드·본문을 검색합니다. 검색 결과에서 선택하면 해당 원본이 왼쪽에 표시되고, 불러오기 버튼을 눌러 오른쪽 작업판으로 가져옵니다. 항목을 바꾸거나 다른 탭을 다녀와도 세션 내에서는 항목별 작업 내용이 유지됩니다. 폴더 자체는 편집 대상에서 제외합니다.

### 기타 번역 화면

왼쪽 입력칸과 오른쪽 읽기 전용 결과칸 두 개만 배치합니다. 왼쪽 아래에는 **언어 선택 / 부분 번역 / 전체 번역**만 표시합니다. 부분 번역은 왼쪽에서 드래그한 구간만 선택한 언어로 교체하고, 전체 번역은 원문을 유지한 채 오른쪽에 표시합니다. 좁은 화면에서는 입력칸·버튼·결과칸 순서로 세로 배치합니다.

탭별로 본문, 선택 범위, 되돌리기 기록, AI 수정 미리보기, 전체 번역 결과를 세션 내에서 따로 유지합니다. 캐릭터별 작업 초안과 기타 번역의 입력 내용은 로컬 저장소에 자동 보관합니다.

## 모델명과 연결 표시

현재 공식 API는 RisuAI 설정의 메인·보조 모델 이름을 직접 읽는 기능을 제공하지 않습니다. 응답에 `model` 식별자가 포함되면 해당 이름을 자동 표시하고 마지막으로 확인한 이름을 보관합니다. 이름을 제공하지 않는 연결은 **모델 이름을 클릭해 메인·보조의 표시 이름을 직접 지정**할 수 있습니다. 이 이름은 화면 표시용이며 실제 호출 모델은 항상 RisuAI의 메인·보조 설정을 따릅니다.

**연결 확인** 플러그 아이콘은 선택한 모델에 짧은 요청을 보내 확인합니다. 이 요청에도 모델 사용량이 발생할 수 있습니다. 실제 수정·번역 요청도 연결 상태를 갱신합니다. 상태는 메인과 보조를 별도로 기록하며, 최근 요청 결과를 나타냅니다. 지속적으로 접속 상태를 감시하는 표시는 아닙니다. 취소로 응답을 확인하지 못한 경우 회색으로 돌아갑니다.

플러그인을 다시 열어 실행할 때는 모델 이름만 복원하고 연결 상태는 미확인으로 시작합니다. 확인 중에는 점이 노란색으로 표시됩니다.

## 원본·백업

- **처음 가져온 원본:** 항목을 작업판으로 가져올 때 플러그인의 기기 로컬 저장소에 보관합니다. 이후 반영해도 처음 원본은 유지합니다. 디스크립션도 별도로 보관합니다.
- **반영 직전 백업:** 반영할 때마다 당시 원본을 추가로 보관합니다. 봇마다 로어북·디스크립션을 합쳐 최근 12회를 유지합니다.
- **작업 초안:** 편집 중 로컬 저장소에 자동 보관하며, 같은 세션에서 항목·탭을 오갈 때 유지합니다. 불러오기 버튼을 누르면 선택한 원본 또는 AI 결과로 작업판을 다시 채웁니다.
- **복원:** 원본·백업 보기에서 작업판 복원을 누르고 내용을 확인합니다. 실제 원본 복구는 반영 버튼을 눌러 완료합니다.
- **내보내기:** 현재 작업 초안과 해당 초안의 반영 기준 원문을 JSON으로 내려받습니다.

백업·초안은 **현재 기기/브라우저의 RisuAI 로컬 저장소**에 저장합니다. 다른 기기로 자동 동기화되지 않으며, 브라우저의 사이트 데이터나 RisuAI 로컬 데이터를 지우면 함께 없어질 수 있습니다. 계속 보관할 자료는 JSON으로 내보내세요. AI 미리보기와 전체 번역 결과는 세션 내 표시용이며 초안 복원 대상에 포함되지 않습니다.

반영 시 최신 캐릭터 데이터를 다시 읽어 변경한 필드만 합치고, 다른 항목과 채팅·기타 설정은 유지합니다. 원본의 같은 필드가 다른 곳에서 변경되었으면 충돌을 표시합니다. 저장을 검증하지 못했거나 백업 저장에 실패했으면 성공으로 표시하지 않습니다.

## 모델 호환성

공식 `runLLMModel` API의 `model` / `submodel` 모드를 사용합니다. 모델 제공 플러그인도 연결할 수 있도록 `allowPlugins`를 활성화했습니다. 이 플러그인은 모델 제공자로 등록하거나 채팅 자동 실행 훅을 등록하지 않습니다.

RisuAI 버전에 따라 플러그인 iframe으로 스트리밍을 전달하지 못할 수 있습니다. 이 경우 오류 안내에 따라 RisuAI에서 스트리밍을 끄고 다시 요청하세요. 긴 본문이 잘리면 RisuAI의 응답 토큰 한도를 늘리거나 범위를 나눠 번역하세요. 플러그인은 모델 자체의 출력 한도를 변경하지 않습니다.

**결과 받기 취소**는 이후 응답의 적용을 막습니다. RisuAI 요청 API에 취소 신호 인자가 없어 이미 전송된 요청이나 과금까지 취소하지는 못합니다.

캐릭터 편집 범위는 `globalLore` 및 `desc`입니다. 기타 번역은 캐릭터와 별개인 자유 입력 작업입니다. 채팅별 로어북·공유 모듈 로어북은 별도 데이터이므로 이 스튜디오의 대상에 포함되지 않습니다.

## 개발·검증

다른 컴퓨터나 새 Codex 채팅에서 이어서 개발하려면 `START_HERE.md`와 `HANDOFF.md`를 먼저 읽으세요. 전달 ZIP에는 이전 대화 없이 이어받을 수 있는 `AGENTS.md`, 재개용 문구, 설치 JS와 전체 소스가 포함됩니다.

외부 런타임 의존성 없이 JavaScript 파일 하나로 빌드됩니다. Node.js 22 이상에서:

```sh
node scripts/build.cjs
node --test tests/core.test.cjs
node scripts/preview.cjs
```

미리보기 주소는 `http://127.0.0.1:4173`입니다. **가상 봇과 모의 AI 응답**으로 동작하며 실제 RisuAI 데이터나 모델에는 연결되지 않습니다. `preview/mock.js`는 설치용 파일에 포함되지 않습니다.

서버 없이 확인하려면 `preview/standalone.html`을 브라우저에서 직접 열면 됩니다. 이 파일도 가상 데이터와 모의 응답만 사용합니다.

브라우저 검증은 `npm install`, `npx playwright install chromium` 후 `npm run test:browser`로 실행합니다. 설치된 Edge를 사용하려면 `PLAYWRIGHT_CHANNEL=msedge` 환경변수를 지정할 수 있습니다. 테스트는 자체 임시 서버를 시작합니다. 메인·보조 라우팅과 모델명, 상태 점, 두 테마와 스크롤 색, 탭별 내용 보존, 기타 번역의 전체·부분 처리, 번역 보기 전용 동작, 원본 반영·복원, 응답 취소·충돌, 모바일 화면과 단일 HTML 미리보기를 검증합니다.

전달용 ZIP을 다시 만들려면 `node scripts/package.cjs`를 실행합니다. `deliverables/`에 개발 ZIP과 SHA-256 파일이 생성됩니다. ZIP 내부의 `MANIFEST.json`은 파일별 무결성 확인용입니다.

실제 사용자의 RisuAI 인스턴스 및 모델을 호출하는 설치 후 통합 검증은 이 프로젝트 환경에서 수행하지 않았습니다.
