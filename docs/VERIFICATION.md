# 검증 기록 · 1.0.0

기준일: 2026-11-24.

- 반영 버튼 문구 중앙 정렬 검사에 마지막 글자와 화살표 사이 6px 이상 간격 검사를 추가했다.

- 코어 테스트 **17개 통과**: 원본 병합·충돌, 봇 재정렬, 중복/ID 없는 항목, 백업 실패·쓰기 권한 거부, 최초 원본 보존, 디스크립션 반영, 백업 한도, 모델 오류·응답·스트리밍 파싱, 수정 프롬프트 원문 전달, 번역 프롬프트 유지.
- 설정창의 기본 프롬프트 표시·편집·자동 저장, 디스크립션·로어북 AI 요청에 사용자 프롬프트 전달, 플러그인 재초기화 후 저장된 프롬프트 복원을 모의 브라우저에서 확인했다.
- 320/390/600/800px에서 두 테마의 원본 영역 → 불러오기 버튼 → 작업 영역 순서, 반영 문구의 수평·수직 중앙 정렬, 가로 넘침 없음을 확인했다. 데스크톱의 좌우 배치도 기존 검증을 통과했다.
- 모의 브라우저 검증 통과: 모델 선택/이름/점 상태, 두 테마 저장, 라이트 스크롤 색, 검색 아이콘 정렬, 로어북 두 드롭다운 및 검색, 항목별 작업판, 최초 원본 복원, 디스크립션 원본·AI 가져오기, 전체/부분 번역, 반영 전 원본 보존, late 응답/취소, 기타 번역 두 칸, 모바일 폭, 데스크톱 화면 맞춤.
- 단일 `preview/standalone.html`을 파일 URL로 직접 열고 모의 번역 동작을 확인했다.
- 브라우저 테스트는 임시 포트의 자체 서버를 쓰도록 변경했다. 이전 PC의 4173 서버가 없어도 된다.
- 실행 환경: Node.js 24.22.3, 번들 Playwright, 설치된 Microsoft Edge의 headless 모드. 브라우저 채널은 환경변수로 지정했다.
- 전달 ZIP은 별도로 압축 해제해 파일별 SHA-256과 내용을 검사하고, 압축 해제본의 빌드·테스트를 확인한다.

**실제 RisuAI 설치/데이터/모델 연결을 검증한 결과는 아니다.** 포함된 미리보기 데이터는 모두 샘플이다.
