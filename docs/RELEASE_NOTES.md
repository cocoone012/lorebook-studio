# 로어북 스튜디오 & 번역기 1.0.0

배포일: 2026-11-24. 첫 정식 배포 버전입니다.

저장소: https://github.com/cocoone012/lorebook-studio

## 설치

[설치용 JS 다운로드](https://github.com/cocoone012/lorebook-studio/releases/download/v1.0.0/lorebook-studio-v1.0.0.js)에서 파일을 내려받을 수 있습니다. Release의 Assets에서 같은 JS 파일을 선택해도 됩니다.

RisuAI 설정 → 플러그인 → 아래쪽 `+` 버튼에서 `dist/lorebook-studio-v1.0.0.js`를 가져옵니다. 기존 설치가 있으면 같은 플러그인의 업데이트로 가져옵니다.

플러그인 식별자와 기존 초안·백업·설정의 저장 키를 유지합니다. JSON이나 개발 ZIP은 RisuAI 설치 파일이 아닙니다.

플러그인 목록·설정 메뉴·햄버거 메뉴의 표시 이름은 **로어북 스튜디오 & 번역기 v1.0**입니다. GitHub 고정 JS를 업데이트 주소로 등록했습니다. 이전 로컬 설치본에 업데이트 주소가 없다면 이 배포본을 한 번 수동으로 다시 가져옵니다. 이후 더 높은 버전이 GitHub에 올라오면 RisuAI의 업데이트 버튼으로 가져올 수 있습니다.

## 포함 기능

- 봇 디스크립션과 로어북의 원본 보기, 직접 편집, AI로 불러오기, 명시적 반영.
- 전체 번역 별도 보기, 선택 영역 부분 번역, 독립된 기타 번역 탭.
- RisuAI의 메인·보조 모델 선택과 연결 확인.
- 설정창에서 AI 불러오기 기본 프롬프트 편집·자동 저장.
- 최초 원본과 반영 직전 백업, 동시 수정 충돌 검사, 되돌리기·다시 실행.
- 다크·라이트 테마, 모바일 세로 배치, 중앙 정렬된 반영 버튼.

## 검증

코어 및 모의 브라우저 검증의 범위와 결과는 `VERIFICATION.md`를 참고합니다. 실제 RisuAI 설치와 실제 모델 호출은 개발 환경에서 검증하지 않았습니다. 실제 앱 테스트는 사용자가 직접 진행합니다.
