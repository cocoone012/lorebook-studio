# 실제 RisuAI에서 테스트하기 · 1.0.0

사용자가 직접 설치하고 확인하는 순서입니다. 실제 앱·모델 테스트는 아직 완료하지 않았습니다.

## 파일 선택

- `dist/lorebook-studio.js`: RisuAI에 가져올 설치 파일.
- `dist/lorebook-studio.json`: 같은 코드와 플러그인 메타데이터를 담은 보관용 JSON. 플러그인 가져오기에는 사용하지 않습니다.
- `preview/standalone.html`: 가상 데이터·모의 AI만 사용하는 오프라인 미리보기.

현재 공식 RisuAI의 `importPlugin`은 `.js`/`.ts` 스크립트를 읽고 `//@name`, `//@api` 헤더를 해석합니다. JSON 레코드를 모듈이나 로어북으로 가져와도 이 플러그인이 설치되지 않습니다.

공식 근거: https://github.com/kwaroran/Risuai/blob/main/src/ts/plugins/plugins.svelte.ts (`importPlugin`). 확인일: 2026-11-24.

## 설치와 확인

1. RisuAI 설정 → 플러그인 → 플러그인 가져오기에서 `dist/lorebook-studio.js`를 선택합니다. RisuAI가 표시하는 설치·권한 안내를 확인합니다.
2. 설정 또는 햄버거 메뉴의 **로어북 스튜디오 & 번역기**를 엽니다. 세 탭이 표시되고 캐릭터 목록을 읽는지 확인합니다.
3. 테스트할 봇을 복제하고 그 복제본을 선택합니다. 원본 디스크립션과 로어북 항목에 짧은 테스트 문장을 준비합니다.
4. **디스크립션**에서 **그대로 불러오기**를 누르고 작업판을 수정합니다. 반영 전에는 봇 원본이 유지되는지, **디스크립션에 반영** 후에는 선택한 복제본만 바뀌는지 확인합니다.
5. **로어북**에서 항목 선택·검색·불러오기·반영을 확인합니다. 다른 로어북 항목과 채팅이 유지되는지도 확인합니다.
6. 상단에서 메인 모델을 선택하고 플러그 아이콘으로 연결을 확인합니다. 보조 모델도 같은 순서로 확인합니다. 실제 모델 요청에는 설정된 연결의 사용량이 발생합니다.
7. **기타 번역**에 `Hello, world!`를 입력하고 한국어 전체 번역을 실행합니다. 왼쪽은 유지되고 오른쪽에 번역이 표시되는지 확인합니다. 이어서 왼쪽의 일부를 선택하고 부분 번역을 눌러 선택 범위만 바뀌는지 확인합니다.
8. 디스크립션·로어북에서도 전체 번역은 결과칸에만 표시되고, 부분 번역은 작업판의 선택 범위만 바꾸는지 확인합니다. AI로 불러오기에서는 짧은 수정 요청으로 결과를 확인합니다.
9. 다크·라이트 모드, 탭 이동 후 작업 내용 유지, 원본·백업의 작업판 복원을 확인합니다. 복원 내용도 반영 버튼을 눌러야 봇에 저장됩니다.
10. 상단 설정창에서 **AI로 불러오기 기본 프롬프트**를 수정하고 AI 불러오기를 실행합니다. 다시 열거나 재실행해도 설정이 유지되는지 확인합니다. 모바일에서는 원본 영역 → 불러오기 버튼 → 작업 영역 순서인지, 두 반영 버튼의 문구가 중앙에 있는지 확인합니다.

## 문제가 생기면

RisuAI 버전, 웹/앱 구분, 실패한 단계, 메인/보조 선택, 화면에 나온 오류 문구를 전달해 주세요. API 키는 필요하지 않습니다. 스트리밍 전달 오류가 표시되면 RisuAI에서 스트리밍을 끈 뒤 재시도합니다.
